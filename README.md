# 🍔 Fresheat – Fast Food & Restaurant React Next.js Template

**Fresheat** is a modern and responsive React Next.js template built specifically for fast food chains, restaurants, cafes, bakeries, seafood outlets, catering businesses, and personal chef portfolios. Designed with a clean and fresh look, Fresheat helps you create a professional and user-friendly online presence with ease.

> 🚀 Built with **Next.js v15.1.3+** and **Bootstrap 5**, this template offers reusable components, high-speed performance, and mobile responsiveness.
